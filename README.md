# 🌐 Language Translator

A simple, responsive, and user-friendly web application that allows users to translate text between multiple languages. Built using HTML, CSS, and JavaScript, the application integrates the MyMemory Translation API to provide translations quickly and easily.

## ✨ Features

* **Multi-language Translation:** Translate text between 10 languages.
* **Language Swap:** Switch the source and target languages with one click.
* **Character Counter:** Track input text up to a maximum of 500 characters.
* **Copy Translation:** Copy translated text to the clipboard.
* **Text-to-Speech:** Listen to both the original text and its translation.
* **Clear Text:** Clear the input and output fields instantly.
* **Responsive Design:** Works on desktop, tablet, and mobile screens.
* **User Feedback:** Displays loading, success, and error messages.

## 🛠️ Technologies Used

* **HTML5** — Structures the application.
* **CSS3** — Provides styling, animations, and responsive layouts.
* **JavaScript** — Handles application logic and user interactions.
* **MyMemory Translation API** — Translates text between supported languages.
* **Web Speech API** — Provides browser-based text-to-speech functionality.
* **Clipboard API** — Copies translated text to the clipboard.

## 🚀 Getting Started

### Prerequisites

* A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
* An active internet connection for translation requests.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/aman0117-crypto/CodeAlpha_Language-Translator.git
```

**2. Navigate to the project directory**

```bash
cd CodeAlpha_Language-Translator
```

**3. Run the application**

Open `index.html` directly in your web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## 📖 How to Use

1. Open the Language Translator application.
2. Select the source language in the **From** dropdown.
3. Select the desired target language in the **To** dropdown.
4. Enter the text you want to translate. The maximum input length is 500 characters.
5. Click the **Translate** button.
6. View the translated text in the output field.
7. Use the copy button to copy the translation or the speaker buttons to listen to the text.
8. Use the swap button to exchange the selected languages and text.
9. Click **Clear** to reset the input and output fields.

## 🔌 API Information

This project uses the [MyMemory Translation API](https://mymemory.translated.net/doc/spec.php) to process translation requests.

An internet connection is required to translate text. Translation availability and quality may depend on the external API service.
